# mindcolor®

Strona marki mindcolor® zbudowana w Next.js i przygotowana do wdrożenia na
Vercel.

## Prerequisites

- Node.js `>=20.9.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Wdrożenie na Vercel

1. Podłącz repozytorium do Vercela.
2. Wybierz Framework Preset: `Next.js`.
3. Pozostaw Output Directory bez ręcznego nadpisania.
4. Opcjonalnie ustaw `NEXT_PUBLIC_SITE_URL` na docelowy adres strony.

Vercel uruchomi standardowy skrypt `npm run build`.
